# AWS Student Community Day - UX & Product Redesign

## 🎯 Objective
Redesign the AWS Student Community Day website from a static informational landing page into an interactive **Student Event Hub**.

## 🚀 Key UX & Product Improvements
1. **Clear Audience & Track Tagging:** Immediately informs students of difficulty levels (`Beginner`, `DevOps`, `AI/ML`).
2. **Interactive Agenda Filtering:** Eliminates wall-of-text schedules by allowing students to filter talks dynamically by interest.
3. **Pre-Event Preparation Checklist:** Guides attendees on prerequisites (AWS Free Tier, Docker, Git) so they arrive prepared for hands-on sessions.
4. **Enhanced Registration Flow:** Seamless modal submission with explicit confirmation state and interactive schedule bookmarking.
